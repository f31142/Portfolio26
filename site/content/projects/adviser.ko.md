## 활동 목적

서류 첨삭이나 초안 작성이 필요한 고객이 요청사항과 파일을 제출하고, 관리자가 신청을 검토해 작업을 진행할 수 있는 웹앱을 만들었습니다. 고객과 관리자가 신청부터 결과물 전달까지 작업 상태와 대화를 한곳에서 확인할 수 있도록 하는 것이 목표였습니다.

## 맡은 역할

개인 활동으로 고객과 관리자에게 각각 필요한 기능을 정리하고, 로그인과 작업 화면의 동작을 구체화했습니다. 고객은 서비스를 신청하고 자신의 작업을 확인할 수 있게 했고, 관리자는 접수된 요청과 파일을 확인하고 작업을 관리하도록 구성했습니다. 코드 수정과 배포 문제 해결에는 ChatGPT의 도움을 받았습니다.

## 수행 과정과 구현 방식

먼저 서비스 신청, 관리자 검토, 작업 진행, 고객 완료 확인으로 이어지는 흐름을 정리했습니다. 그다음 고객과 관리자가 같은 로그인 화면을 쓰되, 로그인 후에는 각 역할에 필요한 메뉴가 표시되도록 요구사항을 정했습니다. 접속 방법은 하나로 통일하면서, 각 화면에서는 필요한 작업을 쉽게 찾을 수 있도록 하기 위해서였습니다.

사용 중에 새로고침하면 메인 화면으로 돌아가는 문제를 발견했습니다. 작업 상세 화면에서 내용을 확인하던 흐름이 끊기지 않도록 현재 화면을 유지하는 기능을 요청했고, 작업 내 대화도 새로고침 없이 갱신되도록 개선했습니다.

## 배운 점과 개선 방향

실제로 운영할 수 있는 비즈니스 사이트를 만들려면 화면 구성 외에도 결제 수단 연동과 파일 업로드처럼 고려해야 할 요소가 많다는 점을 배웠습니다. 또 같은 서비스라도 고객과 관리자가 화면에서 하려는 일이 다르므로, 역할별로 필요한 기능을 먼저 정리해야 한다는 점을 알게 되었습니다. 다음에는 고객과 관리자 각각의 사용 시나리오를 작성하고, 로그인부터 작업 완료까지 새로고침과 화면 이동이 끼어들어도 흐름이 이어지는지 단계별로 확인하고 싶습니다.
